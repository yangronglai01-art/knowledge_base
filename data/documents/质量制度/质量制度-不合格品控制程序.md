# 质量制度：不合格品控制程序

> 文档类别：质量制度　|　所属部门：质量部　|　密级：3
> 本文为内部质量管理文件，供质量部、生产部及相关授权部门使用。

## 一、目的

规范不合格品的识别、标识、隔离、评审与处置，防止不合格品被误用、误发，确保产品质量。

## 二、适用范围

适用于原材料、外协件、半成品、成品在采购、生产、检验、交付各环节发现的不合格品。

## 三、职责划分

- **质量部**：负责不合格品的判定、标识、评审组织与处置监督；
- **生产部 / 仓库**：负责不合格品的隔离、存放与配合处置；
- **相关部门**：参与评审，落实纠正措施。

## 四、控制流程

1. **发现与报告**：检验或使用中发现不合格，立即报告并停止流转；
2. **标识**：对不合格品粘贴红色「不合格」标识，注明编号、日期；
3. **隔离**：将不合格品移入不合格品区，与合格品严格分开存放；
4. **评审**：由质量部组织对不合格品进行评审，判定处置方式；
5. **处置**：按评审结论执行返工、返修、让步接收或报废；
6. **记录**：全过程记录，形成《不合格品处理单》。

## 五、处置方式

| 方式 | 适用情形 |
| --- | --- |
| 返工 | 经返工后可满足规定要求 |
| 返修 | 经返修后满足预期用途但不完全符合原要求 |
| 让步接收 | 不影响使用且经授权批准 |
| 报废 | 无法使用或处置不经济 |

## 六、纠正与预防

- 对重复发生的不合格，应分析根本原因，制定并实施纠正措施；
- 纠正措施实施后应验证其有效性，必要时更新相关文件。

## 七、记录保存

- 《不合格品处理单》及评审记录归档，保存期按文件控制要求执行。
