# 产品技术手册：BSL-75A 螺杆空压机技术参数

> 文档类别：产品技术手册节选　|　所属部门：技术部　|　密级：3
> 本文为内部技术资料，仅供技术部及相关授权部门查阅。

## 一、机型说明

BSL-75A 为固定式风冷喷油螺杆空压机，采用直联传动，适用于对气源稳定性要求较高的连续供气工况。本文列出核心技术与选型参数，供技术方案设计与售前选型参考。

## 二、主机参数

| 项目 | 参数 |
| --- | --- |
| 主机型式 | 双螺杆、阴/阳转子 4/6 齿 |
| 转子材质 | 特种合金钢，表面渗氮处理 |
| 轴端密封 | 机械密封 + 迷宫密封 |
| 主机转速 | 2960 r/min |

## 三、整机性能参数

| 项目 | 参数 |
| --- | --- |
| 额定功率 | 75 kW |
| 排气量（0.8 MPa） | 13.2 m³/min |
| 额定排气压力 | 0.8 MPa（可设定 0.7–1.0 MPa） |
| 比功率 | ≤ 6.5 kW/(m³/min) |
| 电源 | 380 V / 50 Hz / 3 相 |
| 冷却方式 | 风冷 |
| 润滑方式 | 喷油润滑 |

## 四、结构组成

1. **压缩系统**：螺杆主机 + 进气阀 + 最小压力阀；
2. **分离系统**：油气分离器（油分桶）+ 油分芯，排气含油量 ≤ 3 ppm；
3. **冷却系统**：铝制板翅式冷却器 + 轴流风机；
4. **控制系统**：PLC 控制器，支持本地/远程控制、故障记录；
5. **过滤系统**：空滤、油滤、油分芯三级过滤。

## 五、电气与保护参数

| 保护项 | 动作值 |
| --- | --- |
| 排气温度过高报警 | ≥ 100℃ |
| 排气温度过高停机 | ≥ 110℃ |
| 排气压力过高保护 | ≥ 额定压力 × 1.1 |
| 电机过载保护 | 额定电流 × 1.15 |

## 六、安装要求

- 机组四周预留 ≥ 1 m 检修空间，顶部预留 ≥ 1.5 m 空间；
- 基础平整，建议做减振垫处理；
- 进、排气管路通径不得小于机组接口通径，弯头尽量减少。

## 七、选型注意事项

- 高原、高温地区应按修正系数对排气量进行折算；
- 连续满载工况建议预留 10%–15% 余量；
- 粉尘、腐蚀性气体环境需另行加装进气预处理装置。
