# 工艺规范：螺杆转子磨削工艺要求

> 文档类别：工艺规范　|　所属部门：生产部　|　密级：4
> 本文为内部核心工艺文件，仅限生产部及相关授权人员查阅。

## 一、适用范围

本规范适用于螺杆空压机主机阴、阳转子的精磨削工序，覆盖转子型线齿面磨削的工艺准备、参数设定、过程控制与检验要求。

## 二、工艺准备

1. **设备**：数控螺杆磨床，砂轮修整装置、冷却系统工作正常；
2. **工装**：转子专用夹具、顶尖、拨盘，装夹前清洁并检查定位面；
3. **砂轮**：选用与转子型线匹配的成型砂轮，装机前做静平衡；
4. **毛坯**：转子经粗加工、热处理（渗氮/淬火）并完成时效，留精磨余量。

## 三、工艺参数

| 项目 | 参数要求 |
| --- | --- |
| 磨削余量 | 单边 0.10–0.20 mm |
| 砂轮线速度 | 35–45 m/s |
| 工件转速 | 根据型线修正系数设定 |
| 进给量 | 精磨 0.01–0.03 mm/次 |
| 冷却液 | 专用磨削液，压力、流量满足冲洗要求 |

## 四、过程控制要点

1. 每班开工首件进行型线检测，确认合格后方可批量加工；
2. 磨削过程中监控砂轮磨损，及时修整，保证型线精度；
3. 控制磨削温升，防止烧伤；齿面不得出现磨削裂纹、烧伤痕迹；
4. 每件加工后测量齿顶圆直径、导程与齿厚，做好过程记录。

## 五、检验要求

- 齿面粗糙度 Ra ≤ 0.4 μm；
- 型线误差、导程误差满足图纸要求；
- 齿面不得有裂纹、烧伤、磕碰伤；
- 抽检首末件，填写《螺杆转子磨削工序检验记录》。

## 六、安全与环保

- 操作人员须经培训持证上岗，穿戴防护用品；
- 冷却液按环保要求收集、更换，不得随意排放。
